# Evidence provenance

`offline/` is generated by `npm run evidence` against the live local synthetic banking UI. Its `capability.json` is a **hand-authored fixture**, not a model-discovered workflow. The same fixture is written to `tests/example-capability.json` for convenient offline replay.

| Directory | Intended observation |
|---|---|
| `offline/normal/` | Successful replay for a different member |
| `offline/not-found/` | `business_outcome`, code `member_not_found` |
| `offline/transient/` | One declared Retry recovery, then success |
| `offline/handoff/` | Same-session control transfer and resume with an explicitly simulated operator |
| `offline/denied/` | Hard permission failure and diagnostic snapshot |

Each run records `events.jsonl`; failure and intervention paths additionally capture `failure-state.json`. These are redacted accessibility snapshots, not full DOM dumps or screenshots. Repeating a command in the same output directory appends to the event log; session IDs distinguish runs.

**Genuine local evidence:** `discovery/` contains the successful Qwen2.5 3B model-driven run and its generated artifact. It used six calls (5,641 input tokens and 366 output tokens, all computed locally). `replay/` and `generated-not-found/`, `generated-transient/`, `generated-handoff/`, `generated-denied/` execute that exact artifact. Their provenance and verification files bind it by SHA-256. Replay makes zero model calls. The handoff operator in these automated checks is explicitly simulated.

`discovery-attempt-1/` through `discovery-attempt-9/` preserve unsuccessful development runs. Prompt/schema refinements improved valid control selection and completion recognition. The final saved success does not establish a repeated-discovery reliability rate. A separate real-person handoff is recorded under `human-handoff/`. The operator verified the session and resumed automation; the same session then returned success. The generated-handoff and offline-handoff runs remain explicitly simulated.

Use synthetic data only. Inspect generated files before publishing; the demo's limited redaction does not establish production privacy guarantees.
